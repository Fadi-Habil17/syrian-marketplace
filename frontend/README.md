# Web foundation

Next.js 15 / React 19 / Tailwind / Redux Toolkit shell. Root `npm run dev:frontend` starts Arabic `/ar` and English `/en` setup pages; `/` redirects to Arabic. There are no business or admin screens yet. Browser REST requests will use the server-only API client and Actions; authenticated sockets use backend-issued scoped credentials. Follow root README for install/build and full delivery checklist.
