# Mobile foundation

Expo SDK 54, React Native 0.81, React 19.1, TypeScript. From root run `npm run build:packages` then `npm run dev:mobile`, or after root installation `cd mobile` and `npx expo start`. Use a compatible SDK 54 development build (current Expo Go may target a newer SDK). Android emulator reaches the host at `10.0.2.2`; physical phones need its LAN address and firewall permission. iOS simulator/native build requires macOS or EAS. Configure future Expo project ID and push permissions before delivery. Bundle identifiers in app.json are provisional local defaults; replace them with team-owned identifiers before publication. No APK, review link, backend login or business features exist yet.

The setup screen uses explicit per-view text/layout direction for Arabic/English. Future navigation/forms must apply native RTL/reload rules and device tests; do not claim full app RTL from this screen. Mobile retains Expo's expected React 19.1.0 while web uses patched 19.1.10. `metro.config.js` resolves every native `react`/subpath import from the mobile workspace so hoisted native packages cannot import web React. Expo handles the other workspace defaults; autolinking module resolution is enabled. See [Expo monorepo guidance](https://docs.expo.dev/guides/monorepos/) and [custom resolver documentation](https://docs.expo.dev/guides/customizing-metro/). Native device verification is still required.
