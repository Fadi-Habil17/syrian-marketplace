## Status definitions

| Status  | Meaning                                                                                   |
| ------- | ----------------------------------------------------------------------------------------- |
| PASS    | Executed; the stated assertion was met. Applies only to its stated scope.                 |
| FAIL    | Executed or inspected and a stated requirement was not met.                               |

| NOT RUN | Not executed. No inference of success from compilation, source inspection or other tests. |
