## Chosen design

**Dukkan & Hara: a market close to home.** Retain forest green actions, warm cream surfaces and restrained gold accents. Use a locally relevant existing souq image, clear bilingual headings and short supporting text. Do not introduce fabricated activity counts, testimonials or trust guarantees.

The hero prioritizes actual search. Three workspace cards explain what is available. The “How it works” tabs expose four useful steps per journey, with a real destination and correct simulated funding terms. Arabic has its own copy, direction and number formatting; email and password entry retain LTR direction.

Web and native auth share the same visual hierarchy, persistent labels, password visibility controls and error states. Wide web forms stay narrow inside a split layout; phone layouts remove the story panel. Native forms retain safe areas and scroll with the keyboard. Appearance is Light, Dark or System, using semantic tokens throughout the shared screen primitives.

See [verification and screenshots](UI_UPGRADE_VERIFICATION.md) and the [media plan](ui-upgrade/MEDIA_PLAN.md) for actual coverage and outstanding assets.

Linear’s signed-in preference screen was not accessed. Its official documentation confirms explicit Light/Dark choices and an OS-following preference; our control and palette are original.
