## Dependency disposition

Current counts are from the actual audit captured for this working tree, not older setup reports. Affected dependency nodes include inherited paths and do not establish 27 independently reachable exploits.

- Nest 10's [SSE advisory](https://github.com/advisories/GHSA-36xv-jgw5-4q75) remains; this application uses REST/Socket.IO, not SSE. Reachability assessment is an inference from source, not a removal of the advisory.
- Prisma's [deepmerge finding](https://github.com/advisories/GHSA-ggr8-5vv4-36mx) affects configuration tooling; repository configuration is trusted, not API input. The audit proposes a Prisma major change; it was not forced during verification.
- Expo Router retains a query-string chain containing an affected [URI decoder](https://github.com/advisories/GHSA-qr28-fpjm-wq7f). The patched decoder's [published package](https://raw.githubusercontent.com/SamVerschueren/decode-uri-component/v0.5.1/package.json) is ESM while the retained consumer is CommonJS; blindly overriding its pre-1.0 API is not a validated fix. Native deep-link behavior remains unverified.
- Metro retains image-size 1.2.1 with [ICNS](https://github.com/advisories/GHSA-w3rx-r6r6-pgpr) and [JXL/HEIF](https://github.com/advisories/GHSA-5p2g-fcmc-qvqq) findings. Application uploads use Sharp, not that parser. That limits one exposure path without approving tooling that handles untrusted build assets.
